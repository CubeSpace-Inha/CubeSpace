# 용어

이 문서로 답하는 것: 문서와 코드에 나오는 말의 뜻. 같은 것은 늘 같은 말로 쓴다.

관련: [01-아키텍처](01-아키텍처.md) · [04-요구사항](04-요구사항.md)

## 장치·연결

| 용어 | 뜻 |
|---|---|
| 큐브 | 패드 위에 놓는 35 mm(최대 40) 정육면체 입력 장치. ESP32-S3-Matrix(A1) |
| 패드 | 큐브를 놓는 판. LED 영역 200 × 133.33 mm, 광센서 77, LED 384. ESP32-S3-Zero |
| 도크 | 큐브 충전대 6칸. 통신 없음 |
| 등록 번호·슬롯 | 큐브의 등록 순서 0~5. 발광 슬롯, USB에서 큐브를 부르는 번호 [권장안 U-31] |
| 링크 | 패드(중앙)와 큐브(주변)의 BLE 연결. 켜진 등록 큐브 전부, 최대 6 |
| LINK up / down | 패드가 PC에 알리는 링크 상태. up = 설정(CFG)까지 끝남 |
| 동기 유효 | 큐브가 SYNC를 300번 이상 받아(`n ≥ 300`) 패드 시각을 따라가는 상태. 이때만 IR 발광 |
| 프레임 | 패드 광학 주기 P = 50 ms. LED 창 → 배경 읽기 → 슬롯 0~5 → 여유 |
| `pad_boot_id`·`cube_boot_id` | 부팅마다 바뀌는 u32 난수. 바뀌면 재부팅으로 본다 |

## 광학·좌표

| 용어 | 뜻 |
|---|---|
| 배경·차분 | 발광 없는 배경 읽기, (슬롯 읽기 − 배경) / 이득 |
| 광학 상태 | NA(안 읽음) · SEARCHING · ON_PAD · OFF_PAD |
| OBS | 패드가 슬롯마다 보내는 광학 원시 창(센서 값 묶음). 좌표는 PC가 계산 [권장안 U-32] |
| 발견 / 추적 창 | 큐브를 찾는 7 × 3 청크(6프레임에 한 바퀴) / 찾은 뒤 3 × 4 창 |
| SAT·sync_fault | 센서 포화 / 이웃 슬롯 빛이 섞이는 동기 이탈 |
| 패드 mm | LED 영역 기준 좌표. 원점 왼쪽 위, x 0~200, y 0~133.33 |
| 칸 | LED 피치 8.33 mm. 경계 띠도 8.33 mm |

## 큐브 상태 (화면 제어)

| 용어 | 뜻 |
|---|---|
| 놓임 | 링크 up ∧ ON_PAD ∧ 최신 CONTACT 닫힘 |
| 놓임 에지 | 놓임이 새로 성립한 순간. 판정은 에지 뒤 0.5 s·이동 ≤ 4 mm 안정일 때 한 번 |
| 들림 · T_lift | 접촉이 떨어짐. 0.5 s 안에 다시 놓으면 아무 일 없음, 넘으면 내림 확정 |
| 묶임 | 큐브에 창 하나가 배정된 상태(코드의 "배정"과 같음) |
| 창 끔 | 묶인 채 그 창을 최소화해 배치에서 뺀 상태. 큐브 아이콘 ✕ |
| `?` 큐브 | 패드 위에 있지만 묶인 창이 없는 큐브(미배정) |
| 고르는 중 | 선택 팝업이 떠 있는 `?` 큐브. 아이콘 `?` 깜빡 |
| 트레이 | 패드 밖 큐브. 지난번 프로그램(`lastProgram`)만 기억 |
| 교체 보호 | 배터리가 낮은 큐브의 창을 지키는 상태. 예비 큐브를 그 창에 놓으면 이관 |
| 이관 | 보호 중인 창의 담당을 예비 큐브로 옮김 |
| 끊김 보류 · T_drop | 링크가 끊긴 큐브를 5 s 기다림. 넘으면 미배정 |

## 창·배치

| 용어 | 뜻 |
|---|---|
| 등록 앱 | 창 제어 대상 앱 3종(VS Code·Edge·메모장). 이 앱의 창만 다룬다 |
| 안 묶인 창 | 큐브가 없는 등록 앱 창. 패드 지도에 보인다 |
| 옛 자리 `home` | 최소화되기 직전 창의 자리. 그 자리에 큐브를 놓으면 다시 올려 묶는다 |
| 선택 팝업 | 빈 곳에 놓았을 때 큐브 자리 근처 모니터에 뜨는 작은 창(지난번 프로그램 → 열린 창 → 최근 → 검색) |
| 배치 | 묶이고 켜진 창(최대 4)을 템플릿 1 전체 · 2 좌우 · 3 좌1·우2 · 4 2×2로 나눈 것. 분할 트리로 저장 |
| 밀기 | 묶인 큐브를 자기 영역 경계 쪽으로 밀어 경계를 옮김. 경계에서 19.5 mm 안, 3 mm 이상 |
| 패드 지도 | 안 묶인 창을 모니터 위치 그대로 앱 색으로 칠한 LED 층. 떠 있는 창 알파 0.25, 최소화 창 0.10 |
| 모양 모드 | 큐브 번호·모양과 묶인 프로그램을 저장한 구성. 모양이 맞으면 실행 [미정 C2]. 화면 제어/AI 모드와 다른 말이다 |
| 판정값 | 창 어댑터의 적용 결과: ok · clamped · mismatch · uncertain |

## 전원·광학 기호

| 용어 | 뜻 |
|---|---|
| 표 A·표 B | 큐브 사용 시간 계산의 두 경우. 8×8 LED 칩의 대기 전류로 나뉜다: 표 A = 칩당 0.6 mA급(64개 약 38 mA), 표 B = 칩당 2.5 mA급(64개 약 160 mA). 시험 C1의 P0 전류가 100 mA 이상이면 표 B, 60 mA 이하면 표 A, 그 사이면 실측값으로 다시 계산 |
| 프로파일 P0~P4 | 시험 C1에서 큐브 보드(A1) 단품 전류를 재는 상태. 전원 시험 빌드가 60 s씩 돈다: P1 켜짐·LED 소등·광고 50 ms, P2 휴대폰 앱과 BLE 연결, P3 = P2 + 어두운 밝기 대표 아이콘, P4 = P2 + 보통 밝기 대표 아이콘, 마지막 P0 = LED에 0을 보낸 뒤 딥슬립 |
| 지연 D | 전원 시험 빌드가 자기 유지(PWR_HOLD)를 켜기 전에 넣는 지연(0~500 ms, 100 ms 간격). 도크 펄스로 켜짐 10/10이 유지되는 최대 D가 300 ms 이상이면 합격(시험 C9-c). 생산 빌드는 D = 0 |
| T_REQ | 큐브 연속 사용 합격선. 표 A 90분, 표 B 45분 [권장안 U-03]. 시험 C7 |
| F_avail | 큐브 자중으로 바닥 스위치 S1의 플런저에 걸 수 있는 최대 힘 = 무게 W × k(k = 앞 미끄럼 패드 선을 축으로 한 무게중심·플런저 거리 비). 선별 기준 1.2 × max(F_op, F_full) ≤ F_avail. F_op = S1이 도통하는 최소 힘, F_full = 레버가 멈춤에 닿는 최소 힘 |
| DC-1 | 더미 큐브. 큐브 없이 쓰는 IR 시험 광원(USB 5 V로 TSAL4400 하나를 켬). 저항 = R1 × 2 |
| V_REF | 패드 광학 기준 신호. 이득 중앙값 센서의 DC-1 증가분(확정 기둥, 최종 RL). 측정 전 임시 800 mV |
| f_c | DC-1을 네 센서 가운데에 두었을 때의 최대 신호 ÷ 센서 바로 위에 두었을 때의 최대 신호(시험 T2 기록). 측정 전 임시 0.25 |
| r_slot | 그 등록 번호 큐브의 IR 세기 비(시험 CT-4, DC-1 대비). CT-4 전에는 1(합격 범위 0.8~1.3) |
| k_on | 켜짐 임계 계수 = 0.5 × f_c(임시 0.125). `TH_ON[slot] = max(TH_ABS, 10σ_n, k_on × r_slot × V_REF)`([펌웨어 03](../02-펌웨어/03-패드-프레임-광학.md)) |
| BRIGHT_ACTIVE·BRIGHT_IDLE | 큐브 8×8 보통 밝기·어두운 밝기 상수. 보통 = 점등분 상한(40 mA) 안에서 시험 C3으로 전류를 재서 정함. 어두움 = 아이콘 색을 구분할 수 있는 최저값(15 mA 안), 실물로 정함. 값은 미정 [실측 필요]. 전환 규칙은 [소프트웨어 05](../04-소프트웨어/05-표시.md) 5절 |

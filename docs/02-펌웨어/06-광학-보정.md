# 광학 보정

이 문서로 답하는 것: 패드 광학을 무엇으로 어떤 순서로 재고 맞추나, 보정은 어떤 파일과 상수를 만들고, 언제 다시 하나.

관련: [03-패드-프레임-광학](03-패드-프레임-광학.md) 6절(판정 식·상수) · [05-선개발-시험](05-선개발-시험.md) 2절(상수 놓는 곳) · [게이트웨이·좌표 6절](../04-소프트웨어/02-게이트웨이-좌표.md)(보정 파일을 읽는 쪽, 1점 확인, 보정 무효) · [패드 하드웨어](../01-하드웨어/02-패드.md) · [제작 시험](../01-하드웨어/05-제작-시험-실측값.md)

- 시험 이름: T n = 패드 시험 PT-n이다([제작 시험](../01-하드웨어/05-제작-시험-실측값.md) 2절). PT-4a는 T4a와 같은 시험이다. PT-1s·PT-2·PT-5a·PT-5b·GAIN-CAL·POS-CAL·EDGE-L은 이 문서가 정한다.
- 측정 전 임시 상수로는 합격 판정을 하지 않는다. 제품 판정 코드가 없는 `pad_test` 단계에서는 PC가 CSV 차분에 같은 식(이득 나눔, TH_ON·TH_OFF)을 적용해 판정한다.
- 상판이 유백 아크릴에서 투명 아크릴로 바뀔 수 있다. 절차는 같다. 빛점 모양이 달라지므로 PT-2와 POS-CAL이 모형 (m, σ)를 다시 맞춘다. 상판 변경은 보정 무효다.

## 1. 보정이 만드는 것

### 1.1 보정 파일 `cal-<패드 serialNumber>.json`(`ver` 2)

칸 목록의 정본은 [게이트웨이·좌표 6절](../04-소프트웨어/02-게이트웨이-좌표.md)이다. 여기서는 뜻과 만드는 단계만 적는다.

| 칸 | 뜻 | 만드는 단계 |
|---|---|---|
| `gain[7][11]` | 센서 이득 g(행 r, 열 c). 77개 중앙값 = 1 | GAIN-CAL |
| `bad` | `[r, c]` 목록. g < 0.2인 센서와 부팅 `bad_map` | GAIN-CAL |
| `curve{m, sigma, h, u, t, edge_u, edge_t}` | 맞춘 빛 모형 (m, σ), 높이 h(= 확정 광학 공간 − 1.2 mm, 센서 끝~상판 아랫면)와 그 모형으로 만든 401점 단조 표 둘(`curve()`·`curve_edge()`), x·y 공용 | POS-CAL |
| `offset_mm` | 그대로 방향의 판 어긋남 `{dx, dy}`. 추정기가 쓴다 | POS-CAL |
| `th_on_mv[6]` | 슬롯별 TH_ON(`optics.h`와 같은 값) | 3절 항으로 계산 |
| `fw` | 이 보정으로 만든 `optics.h`가 든 패드 펌웨어의 HELLO `fw` | 재빌드 뒤 |
| `optics` | `{pillar_mm, rl_ohm, cf_nf, r1_ohm, tape}`: 기둥 높이, RL, CF, 큐브 R1, 확산 테이프 여부 | 기록 |
| `adc` | `{atten_db, reads, sat_mv, sigma_n_mv}`: 감쇠(6), READS, SAT_MV, σ_n | PT-1s, PT-4a |
| `v_ref_mv`, `f_c`, `k_on` | 3절 항 | GAIN-CAL, PT-2 |
| `cube_gain[6]` | 슬롯별 큐브 세기 비 r(DC-1 대비). 빈 슬롯 null | CT-4 |
| `k_cube`, `k_t` | 포화 예산(5.4)에 쓴 값 | IR-BIN, T8a |
| `pos_cal` | `{points, resid_rms_mm, t_levels}`: 쓴 점 수(26, 1차 구역 7), 잔차 RMS, 서로 다른 \|t\| 수 | POS-CAL |

### 1.2 `optics.h`

- `measure/pos_cal.py`가 보정 파일에서 만든다. 손으로 고치지 않는다.
- 담는 것: `INV_G[7][11]`(1/g), `TH_ON[6]`, `SIGMA_N`, `SAT_MV`, `TH_ABS`(50 mV 고정). 뜻과 임시값은 [03 6.1](03-패드-프레임-광학.md).
- 만든 뒤 패드를 다시 빌드한다(약 10분). 새 HELLO `fw`를 보정 파일 `fw`에 적는다. 둘이 다르면 동반 앱이 경고한다.
- 보정 파일 SHA-256은 측정 기록 `meas_id`에 들어간다([10 재생·시험](../04-소프트웨어/10-재생-시험.md) 6절).

## 2. 지그와 시험 광원

### 2.1 좌표

- 판 좌표: 센서·LED 판 뒤 왼쪽 모서리가 원점, x 오른쪽, y 사용자 쪽(mm). 센서 중심과 LED 영역 좌표로 바꾸는 식은 [게이트웨이·좌표 5절](../04-소프트웨어/02-게이트웨이-좌표.md) 6단계다.
- 1차 구역 = 센서 행 0~4 × 열 0~4(25개).

### 2.5 더미 큐브 DC-1

큐브 없이 패드를 재는 IR 광원은 DC-1 하나다. 패드가 켜고 끈다.

| 항목 | 값 |
|---|---|
| 몸체 | 큐브 뚜껑 출력물 1개(바닥면·IR 구멍·미끄럼 패드 자리가 큐브와 같음). 만능기판 자투리로 LED 끝 높이를 큐브와 같게: 들어감 1.0 ± 0.2(상판 윗면에서 1.4). LED를 바꿀 때마다 깊이 막대로 확인 |
| 회로 | USB 5 V(자른 USB 케이블 VBUS·GND) → 큐브 R1 두 개 직렬 → TSAL4400 → 2N3904 컬렉터, 이미터 → GND. 베이스는 1 kΩ을 거쳐 패드 Zero GPIO42. 패드 GND와 선 하나로 잇는다(3선, 약 50 cm) |
| 저항 | 큐브 R1 × 2. R1이 22·47·100·220 Ω이면 44·94·200·440 Ω |
| LED | 2핀 암 헤더에 꽂는다. IR-BIN 중앙값에 가장 가까운 LED를 고정 |
| 전류 | 32~43 mA. 만든 날 재어 기록. 세기는 비율로 판정하므로 정확한 전류는 중요하지 않다 |
| 만든 날 확인 | 전류 32~43 mA, LED를 가린 채 GPIO42 토글 증가분 0 ± 2 mV, 가리지 않은 끔 0 ± 10 mV, 들어감 1.0 ± 0.2 |
| 핀 | GPIO42는 `pad_test`에서만 쓴다. CT-5 에지 빌드(9·10·41)·다중 X1-J 빌드와 같은 빌드에 넣지 않는다 |

### 2.6 `pad_test`에 더할 것

| 항목 | 동작 |
|---|---|
| `IR_TEST = 42` | DC-1 출력. 키 `a` = 스캔마다 켬·끔 번갈아(기본), 키 `i` = 켬 고정 / 끔 고정. CSV에 `ir` 열 |
| `settle_us` | IR을 켜거나 끈 뒤 첫 주소를 읽기 전에 t_s(PT-5b)를 기다림 |
| `us` 열 | CSV 첫 열 `micros()` |
| 키 `r` | READS 1 ↔ 2 |
| `FULL_GRID` | 7 × 11 전체 격자 출력 |
| 시작 줄 | `# cfg fw=… settle_us=… reads=…` |
| 감쇠 | 핀별 감쇠를 지우고 첫 읽기 전 전역 `analogSetAttenuation(ADC_6db)` |
| 루프 | `micros()` 고정 마감 50,000 µs. 확인: `us` 간격 50,000 ± 20 µs(1분) |
| `selfCheck()` | `bad_map` 두 규칙([03 6.6](03-패드-프레임-광학.md)) |
| 키 `f` | 지정 주소·먹스 한 채널을 200 ms 동안 최대 속도로 읽어 `# f,us,mv` 줄 |
| 키 `m r c` | 목표 센서 둘레 모서리 LED 4개(목표에서 가로·세로 ±20.83 mm) 가운데 LED 영역 안의 것만 흰색 32/255(바깥 줄 센서는 2개, 모서리 센서는 1개) |

- CSV에 차분 열은 붙이지 않는다. PC 도구가 `ir` 열로 계산한다: 켬 스캔 − 바로 옆 끔 스캔(같은 센서, 50 ms 간격), 20 Hz.

## 3. 판정 임계에 들어가는 항

TH_ON·TH_OFF·TH_SF 식은 [03 6.1](03-패드-프레임-광학.md) 표에 있다. 여기서는 식의 항을 어떻게 재는지 적는다.

| 항 | 뜻 | 재는 곳 | 측정 전 |
|---|---|---|---|
| V_REF | 이득 중앙값 센서의 DC-1 증가분(켬 − 끔, mV). 최종 RL·확정 기둥에서 | GAIN-CAL | 800 mV |
| σ_n | IR 끔 차분 200프레임의 표준편차(READS 1) | PT-4a | [03 6.1](03-패드-프레임-광학.md) |
| f_c | DC-1을 네 센서 가운데에 둔 V′_max ÷ 센서 바로 위에 둔 V′_max. 영역 안 V′_max/정점의 최솟값이라 영역 안 어디서도 V′_max ≥ 2 TH_ON이 된다 | PT-2 | 0.25 |
| k_on | 0.5 × f_c | PT-2, EDGE-L에서 조정 | 0.125 |
| r_slot | 그 등록 번호 큐브의 세기 비 r(DC-1 대비) = `cube_gain[slot]` | CT-4 | 1(CT-4 합격 범위 0.8~1.3) |
| TH_ABS | 바닥 임계 50 mV, 고정 | | |
| V_clip | 실제로 잘리는 mV. SAT_MV = min(1550, V_clip − 50) | PT-1s | |

- 측정 전 값(f_c 0.25, k_on 0.125, V_REF 800 mV, r 1, g 1)이면 TH_ON 100 mV다. PT-2·GAIN-CAL 전에는 이 값으로 합격 판정을 하지 않는다.
- 기둥 채택 조건이 하나 더 있다: f_c × V_REF × 0.8 ≥ 2 × max(TH_ABS, 10σ_n). 못 맞추는 기둥은 네 센서 가운데에서 바닥 임계에 걸린다.

## 4. 광학 측정

| ID | 무엇 | 방법 | 결과·판정 |
|---|---|---|---|
| PT-1s | 실제 잘림 전압, 6 dB 감쇠 확인 | RL 10 kΩ·기둥 10, DC-1을 J-B 2에 두고 센서를 일부러 포화시켜 켬 원시값 20개. 제품 펌웨어로 바꾼 날 한 번 더 | V_clip ≤ 2.0 V(6 dB 확인). SAT_MV = min(1550, V_clip − 50) |
| PT-2 | 빛점 모양(기록) | 기둥마다 최종 RL에서 DC-1을 ① J-B 2(r1·c4 바로 위) ② J-C 1번 돌린 자리(92.00, 91.83 = 네 센서 가운데)에 두고 5 × 5 차분 20쌍 평균. 손으로 놓지 않음 | r1(있는 이웃 평균 ÷ 정점, r1·c4는 이웃 3개), r_d(있는 대각 2개 평균 ÷ 정점), f_c(②의 V′_max ÷ ①의 정점), 이 셋에 맞춘 모형 (m, σ)(POS-CAL 시작값). T2 이웃 비율 판정은 [제작 시험](../01-하드웨어/05-제작-시험-실측값.md) |
| PT-4a | 차분 잡음 σ_n, LED 간섭 | `pad_test` READS 1, 확정 CF. 조건 a = 전체 검정(LED_EN HIGH), b = 감광 상한 흰색(L = 32, T10 뒤에는 I_cap에 닿는 밝기). 켬 − 끔 200쌍 | σ_n → `SIGMA_N`. 판정은 [제작 시험](../01-하드웨어/05-제작-시험-실측값.md) T4a |
| PT-5a | 주소 전환 안정화 a, 채널당 읽기 c, 먹스 RON | 쓸 RL 1~2개(첫 기둥에서 쓰는 RL과 10 kΩ). 최악 순서: ① 밝음 → 어두움(DC-1 아래 채널 k → 어두운 k+1) ② 어두움 → 약한 빛(정점의 5~20 %) ③ 뜬 이미터 재연결(50 ms 선택하지 않았다가 선택) ④ CF 1 nF일 때만 ADC 채널 전환(밝은 행 약 1.5 V 직후 어두운 다음 행) | \|v(t) − v_final\| ≤ max(1 % × 계단, 2 mV)가 되는 최소 대기 × 1.5, a = max(0.3 ms, 그 값). ④ 잔류 > 2 mV면 RL ≤ 4.7 kΩ(CF 10 nF)로 제한. 판정 T5, 값은 `frame.h` |
| PT-5b | IR 켜짐 정착 t_s | 한 채널 고정 최대 속도(≥ 10 kHz, 키 `f`) 읽기 중 GPIO42로 DC-1을 켬. 정점·이웃 센서 | 최종값 99 % 도달 시간 × 1.5 = t_s. 0.3 ms보다 길면 `frame.h`를 고치고 P를 다시 계산 |
| EDGE-L | 가장자리 소실 자리, k_on 조정 | 전 영역 보정 뒤 X3-E와 한 세션. 네 변 × 5회 밀어내기(끝에 닿아 정지한 자리에서 시작 포함). 마지막 ON_PAD 원시 중심, `edge_out` 여부, 소실 때 실제 중심(자)을 기록 | 소실 때 큐브 중심이 LED 영역 끝 −15 ~ +15 mm(음수 = 안쪽), 20/20 "이동 ≥ 3 mm ∨ `edge_out`". 하한을 어기면 k_on을 낮추고 상한을 어기면 올린다. "영역 안 V′_max ≥ 2 TH_ON"과 부딪히면 영역 안 헛소실 방지를 먼저 |

## 5. 절차

### 5.1 순서

| 단계 | 할 일 |
|---|---|
| 1차 구역, 스트립 전 | 기둥 10 → `pad_test` 루프 확인 → PT-1s → PT-5a·5b → 첫 기둥 RL 고르기(5.2) → GAIN-CAL-25. 스트립 전이라 GAIN-CAL은 모서리 LED 안내 없이 PC 막대·균형 표시만 쓴다 |
| 1차 구역, 스트립 뒤 | IR-BIN(PT-1s 뒤, 1호기 D1 납땜 전). 기둥마다(10 → 12 → 15 → 19): RL 고르기 → GAIN-CAL-25 → PT-2 → POS-CAL 7점 → 위치 시험(T6). 기둥 확정 뒤 PT-4a |
| 전 영역 | 센서 선별(5.3) → 나머지 52개 설치 → 30분 예열(2 × 2 템플릿 테두리 켬) → GAIN-CAL-77 → 포화 예산 재확인(5.4) → POS-CAL 26점 → `optics.h` 생성·재빌드 → 1점 확인 → EDGE-L |

- 하드웨어 시험 전체 순서는 [제작 시험](../01-하드웨어/05-제작-시험-실측값.md) 2절이다. 보정은 그 순서의 "T6·보정" 자리다.
- 이득 g는 센서의 비라 RL을 바꿔도 그대로 쓴다. 기둥마다 GAIN-CAL-25를 따로 한다(빛이 들어오는 각도가 기둥마다 다르다).

### 5.2 RL 고르기(T1)

1. 기둥마다 DC-1을 J-B 2에 둔다. 1 kΩ부터 올려 V_on ≤ SAT_MV / 2(약 775 mV)를 지키는 가장 큰 후보를 고른다(이득이 r1·c4의 2배인 센서도 GAIN-CAL에서 포화하지 않게). 10 kΩ에서도 증가분 < 300 mV인 기둥은 "신호 부족"으로 적는다.
2. 그 RL로 GAIN-CAL-25를 한다.
3. 최종 RL = 1단계 RL × 1500 ÷ max_i(bg_p99,i + k_T × 1.05 × k_cube × V_s,i)를 후보 값(직렬 조합 포함)으로 내린 값(항은 5.4). 그 기둥의 PT-2·POS-CAL·T6은 최종 RL로 한다.
4. 최종 RL < 470 Ω이면 큐브 R1을 47 → 100 → 220 Ω으로 올린다(6대 같은 값, DC-1도 R1 × 2). 220 Ω에서도 470 Ω 아래면 그 기둥을 뺀다.
5. RL × CF ≤ 47 µs를 지킨다(CF 규칙은 [패드 하드웨어](../01-하드웨어/02-패드.md)).

### 5.3 센서 선별(나머지 52개 설치 전)

- 선별 자리 = 1차 구역 r1·c4 센서 자리를 2핀 암 헤더로 두고 후보를 꽂는다. J-B 2의 DC-1로 켬·끔 20쌍(약 20 s)을 잰다. 패드와 같은 상판·기둥·RL이라 GAIN-CAL과 같은 단위다.
- 선별 폭: 설치 센서의 V_top ÷ V_bot ≤ (1500 − bg) ÷ (500 × k_cube × k_T × 1.05). bg = 센서별 bg_p99,i의 최댓값. bg 300 mV면 1.56.
- 폭 안의 것부터 설치한다. 52개가 모자라면 폭에 가장 가까운 것으로 채우고 그 값을 포화 예산(5.4)에 넣는다. 그래도 V_bot ≥ 500 mV나 예산 여유 ≥ 0을 못 맞추면 추가 구매(같은 품번, 가능하면 같은 로트)를 사용자에게 묻는다.
- 1차 구역 25개는 GAIN-CAL-25에서 같은 폭으로 본다. 넘으면 극단 센서를 여분으로 바꾼다.

### 5.4 GAIN-CAL(센서 이득, 새 지그 없음)

| 항목 | 내용 |
|---|---|
| 광원·모드 | DC-1(IR-BIN 중앙값 LED), `pad_test` 교대 켬·끔(키 `a`), READS 1, 전체 격자 |
| 도구 | `measure/gain_cal.py`가 목표 센서의 현재값·최댓값 막대와 3 × 3 균형 표시(가중 중심 u_x, u_y)를 실시간으로 보인다. 패드는 키 `m r c`로 목표 둘레 모서리 LED를 켠다 |
| 문지르기 | DC-1을 목표 위 ±3 mm 안에서 가로·세로로 촘촘히(줄 간격 약 1 mm) 문지른다. 최댓값이 3 s 동안 오르지 않고 균형 표시가 가운데 근처면 작업자가 키로 확정한다(자동 넘김 없음). 25개 약 4분, 77개 약 10분 |
| 계산 | g_s = V_s ÷ 중앙값(V_s = 확정한 최댓값). g_s < 0.2면 `bad`(단선·역삽입·불량). SAT 비트가 선 표본은 버리고 RL을 한 단계 낮춰 그 기둥의 GAIN-CAL을 다시 한다 |
| 합격 | ① 무작위 5개를 다시 문질러 \|Δg\| ≤ 3 %. ② 주머니 대조: DC-1을 J-B 2(r1·c4)와 J-C 6번 돌린 자리(83.66, 50.17 = r1·c3)에 두고 켬·끔 20쌍 평균한 두 센서 값의 비가 g 비와 3 % 안. 전 영역에서는 J-C 5·6번의 그대로·돌린 자리(r1·c9, r5·c7, r5·c1, r1·c3)를 더한다 |
| 불합격 | 그 센서들을 다시 문지른다. 그래도 넘으면 두 값의 평균을 쓰고 기록한다 |
| `bad` 센서 | 둔 채 측정하지 않는다. 교체하고 GAIN-CAL·POS-CAL을 다시 한다 |

**포화 예산 재확인(GAIN-CAL-77 뒤)**: 가장 센 큐브가 이득이 가장 큰 센서 위에 있고 판이 가장 더울 때도 원시값이 1500 mV 이하여야 한다.

```
max_i [ bg_p99,i + k_T × 1.05 × k_cube × V_s,i ] ≤ 1500 mV,   V_bot ≥ 500 mV
```

| 항 | 뜻 |
|---|---|
| i | 설치 센서 |
| V_s,i | GAIN-CAL에서 잰 센서 i의 DC-1 증가분. 가장 큰 값 V_top, 가장 작은 값 V_bot |
| bg_p99,i | T7 배경(실내 천장등·창가 가운데 큰 조건)에서 센서 i의 99번째 백분위, 같은 RL로 환산(bg ∝ RL) |
| k_cube | IR-BIN으로 장착한 LED r의 최댓값. IR-BIN 전이거나 못 하면 1.3 |
| 1.05 | DC-1·CT-4는 켬 50 %로 재고 제품 슬롯은 켬 10.9 %라 제품에서 LED가 약 4 % 더 밝은 몫 |
| k_T | 판 온도에 따른 센서 감도 증가 = 1 + 0.005 × ΔT(ΔT = T8a 판 온도 상승). 처음 1.13 |
| 1500 | SAT_MV 1550 − 여유 50 |

- 어기면 RL을 한 단계 낮추고(RL 7개 교체) `optics.h`만 다시 만든다. GAIN-CAL은 다시 하지 않는다.

### 5.5 POS-CAL(위치 곡선, J-C)

1. J-C를 턱에 맞춰 얹는다. 광원은 1차 구역에서 `pad_test` + DC-1, 전 영역 최종 보정은 제품 펌웨어 + 1호기(CT-4 합격)다.
2. 13개 주머니에 차례로 놓는다. 놓은 뒤 1 s(큐브면 S1 닫힘 + 1 s)를 기다리고 이어지는 20프레임의 (u_x, u_y)를 평균한다(READS 1).
3. J-C를 180° 돌려 같은 일을 한다. 모두 26점(1차 구역은 2.4의 7점).
4. 맞춤: 모형 (m, σ)(식은 [시험 벡터](../03-인터페이스/04-시험-벡터.md) 가상 광학 절과 부록 `response()`, H = 확정 광학 공간 − 1.2 mm. m 0.5~12, σ 0~8 격자, PT-2 값에서 시작)와 방향별 어긋남 (dx_n, dy_n)·(dx_r, dy_r)을 최소제곱으로 고른다. 1차 구역은 식 14개에 변수 6개다. 곡선 두 표는 그 (m, σ)의 `curve()`·`curve_edge()`다. 추정기는 그대로 방향 (dx_n, dy_n)만 쓴다(평가 판과 같은 기준 변). 돌린 방향은 턱이 반대쪽 두 변에 닿아 상판 치수 오차만큼 어긋남이 달라서 따로 맞춘다.
5. 합격: 잔차 RMS ≤ 0.8 mm, 서로 다른 \|t\| ≥ 4. 잔차 > 2 mm인 점은 다시 놓아 잰다.
6. 다시 재도 잔차 RMS > 0.8 mm면 2차원 보정표(센서 간격 칸 60개의 쌍선형 보정)를 더한다. 이 표는 지금 보정 파일 형식과 추정기에 칸이 없다 [미정: 형식 추가 필요].

### 5.6 `optics.h` 생성·재빌드와 1점 확인

- `pos_cal.py`로 `optics.h`를 만들고 패드를 다시 빌드한 뒤 보정 파일 `fw`를 적는다(1.2).
- 1점 확인: J-A를 턱에 맞춰 얹고 8번 주머니(확인점)에 큐브를 놓는다. 동반 앱 교정 화면이 오차를 보인다. 약 1분, 누구나 한다. 보정 직후와 매 시연·측정 날에 한다.
- 합격 기준과 불합격 처리는 [게이트웨이·좌표 6절](../04-소프트웨어/02-게이트웨이-좌표.md)(≤ 1.0 mm, 넘으면 안착을 고쳐 1회 더, 또 넘으면 다시 보정)이다. 재보정 버튼은 없고 교정은 동반 앱에서 한다 [권장안 U-23].

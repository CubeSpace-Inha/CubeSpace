# 제작 시험과 실측값

이 문서로 답하는 것: 제작 중 어떤 시험을 어떤 순서로 하고 무엇이면 합격인가, 실측으로 정할 값은 무엇이고 정해지면 어디를 고치는가.

관련: [01-큐브](01-큐브.md) · [02-패드](02-패드.md) · [03-도크](03-도크.md) · [04-부품-주문](04-부품-주문.md) · 펌웨어 쪽 판정·보정 [../02-펌웨어/02-큐브.md](../02-펌웨어/02-큐브.md), [../02-펌웨어/03-패드-프레임-광학.md](../02-펌웨어/03-패드-프레임-광학.md), [../02-펌웨어/06-광학-보정.md](../02-펌웨어/06-광학-보정.md)

- 제작 판정에 필요한 시험만 적었다. 위치 정확도·사용 평가 시험은 [펌웨어 05](../02-펌웨어/05-선개발-시험.md)·[광학 보정](../02-펌웨어/06-광학-보정.md)·[소프트웨어 10](../04-소프트웨어/10-재생-시험.md) 몫이다.
- 한 시험이라도 불합격이면 다음 단계로 가지 않는다. 기록은 측정값·판정·날짜.
- 시험 ID: C n = CT-n(큐브), T n = PT-n(패드), D-T n(도크). C12 = CT-12a·CT-12b처럼 글자가 붙은 시험은 같은 번호의 하위 시험이다.
- 광학 측정·보정(PT-1s·PT-2 기록·PT-4a 잡음·PT-5a·5b·GAIN-CAL·POS-CAL·EDGE-L)과 시험 광원 더미 큐브 DC-1·지그 J-A·J-B·J-C는 [광학 보정](../02-펌웨어/06-광학-보정.md)이 정한다.

## 4. 실측으로 정할 값과 고칠 곳

# 도크 (충전 전용 6칸)

이 문서로 답하는 것: 도크를 몇 칸으로, 어떤 회로·접점·치수로 만들고, 켜서 무엇을 확인하는가.

관련: [01-큐브](01-큐브.md) · [02-패드](02-패드.md) · [04-부품-주문](04-부품-주문.md) · [05-제작-시험-실측값](05-제작-시험-실측값.md) · 도크에 올렸을 때 큐브 동작 [../02-펌웨어/02-큐브.md](../02-펌웨어/02-큐브.md)

- 단위 mm. 큐브 L = 35 기준. 기구 값은 큐브 실측값(L_m, L_h)을 넣는 식이다. 도크 3D 파일(`dock.scad`)은 아직 없고 이 문서 값으로 새로 만든다.
- 도크는 충전만 한다. 데이터 통신·위치 인식·PC 연결·칸별 충전 표시가 없다. 패드와 어댑터를 나누지 않는다(도크 단락이 패드 LED를 멈추지 않게).

## 1. 칸 수와 배치

| 항목 | 값 |
|---|---|
| 칸 | 6칸(3 × 2), 칸마다 큐브 1개. 1·2칸을 먼저 만들고 3~6칸을 뒤에 만든다 |
| 중심 간격 | 48. cx 31·79·127, cy 31·79 |
| 바닥 외형 | 160 × 112 |
| 전체 높이 | 약 53(몸체 약 50 + 덮개 3) |
| 단면 | 아래 공간 10(PTC 눕혀 5, 기판 1.6, 배선 3) + 바닥판 t_f 3.0 + 포켓 벽 10 |

## 2. 충전 회로

```
GST25A05-P1J DC 선(플러그 잘라 직결) ─ 입력 기판 ─ C-D 470 µF ─ 버스 AWG22
  ─ 칸마다 RXEF050(PTC) ─ (+) 포고 ─ 큐브 P1
                          (−) 포고 ─ 버스 GND ─ 큐브 P2
```

| 기호 | 부품 | 값 |
|---|---|---|
| PS-D | Mean Well GST25A05-P1J | 5 V 4.0 A, ±5 %, 과부하 110~150 % 딸꾹질(자동 복구), 입구 IEC320-C14, DC 선 16 AWG 1 m |
| AC 코드 | IN-POWER015, 기기 쪽 C13 | |
| C-D | 470 µF 16 V 삼영 KMG 8 × 11.5(슬리브 포함 ≤ 8.5) | 입력 기판 밖(바닥판 밑면 핫멜트), 다리만 기판에. 기판 위에 눕히면 10.1로 아래 공간 10을 넘는다 |
| 버스 | AWG22 2 × 0.2 m | 섀시 7 A |
| F-D1~6 | Littelfuse RXEF050, 칸당 1 | Ih 0.5 A, It 1 A, Ri min 0.50 Ω, R1max 1.17 Ω. 눕혀 장착, PETG에서 띄움 |
| P-D | Mill-Max 0906-1-15-20-75-14-11-0, 칸당 2 | 3절. 구매 20개(도크 12 + C6 시험 2 + 여분 6) |
| 입력 기판 | 만능기판 조각(VLT-PCB008 여분) | 크기 [미정] |

- 잭·퓨즈·홀더 없음. 버스 단락은 어댑터 딸꾹질(≤ 6 A)이 끊고, 한 칸 부분 단락은 그 칸 PTC가 끊는다.

### 2.1 전압 보장값 (최악: 어댑터 4.75 V, 6칸 동시)

| 계약값 | 값 |
|---|---|
| 종료 칸 포고 끝(13 mA, 다른 5칸 130 mA) | ≥ 4.65 V |
| 충전 칸 포고 끝(130 mA) | ≥ 4.45 V(참고) |
| 보통(어댑터 5.00 V) | 위 값 + 0.25 V |
| 큐브 완충 요구 | TP4056 VCC ≥ 4.30 V @ 13 mA(D2 강하 뒤 최악 4.313 V) |
| 접점 저항 | 접점당 ≤ 0.2 Ω |

- 정전압 전환(약 77 mA) 때 VCC가 VBAT의 30 mV 안으로 떨어지면 TP4056이 멈춘다. 최악 여유가 −33 mV라 C6·D-T2에서 충전 끊김이 없는지 본다. 끊기면 큐브 D2 → PMEG2010ER → PTC → 배선 순으로 고친다. 어댑터는 바꾸지 않는다.
- 칸당 충전 130 mA(Rprog 10 kΩ), 종료 약 13 mA. 셀 허용 < 120 mA면 Rprog를 올리고 전류 창도 바뀐다 [권장안 U-90].
- Rprog를 바꾸지 않은 모듈(약 1 A)은 PTC 동작이 보장되지 않는다. U1-B·C6을 통과하지 않은 큐브는 도크에 넣지 않는다.

## 3. 접점과 포고 핀

### 3.1 큐브 쪽 (참고)

| 항목 | 값 |
|---|---|
| 좌표 | P1 = +, P2 = GND, (c ± 7.5, 앞면 + 5). L=35: (10, 5) / (25, 5), 간격 15 |
| 나사 | 나사코리아 3701 M2x4 접시 일자 SUS304. 머리 윗면이 바닥면에서 0.3 ± 0.15 들어감 |
| 미끄럼 패드 | 3개, 0.4 ± 0.05. 도크 바닥이 3개 모두 받친다 |
| 큐브 회로 | P1 ─ D2 1N5819 ─ U1 IN+. 도크 5 V가 닿으면 약 1 s 펄스로 큐브가 켜지고 DOCK_N LOW로 도크를 알아챈다. 뗀 뒤 몇 초 안에 다시 올리면 C3이 덜 방전되어(시정수 약 3 s) 펄스가 안 나올 수 있다. 그때는 버튼으로 켠다 |

### 3.2 포고 핀

| 항목 | 값 |
|---|---|
| 품번 | Mill-Max 0906-1-15-20-75-14-11-0. 작동 창 3.10~4.50, 행정 1.4, 중간 60 gf, 팁 Ø1.07 둥근형, 플랜지 Ø1.83 × 0.41, 꼬리 Ø0.43 × 1.75, 자유 높이 4.50, 정격 2 A |
| 고정 | 칸마다 만능기판 띠(10 × 25)에 2개 납땜(기판 아랫면에서만). 핀 어깨가 기판 윗면에 앉고, 기판 윗면을 바닥판 아랫면에 밀착. 높이 기준면 = 바닥판 아랫면 |
| 간격·좌표 | 15.24(2.54 × 6). P1 = (cx − 7.62, cy − L_m/2 + 5), P2 = (cx + 7.62, cy − L_m/2 + 5). L=35면 cy − 12.5 |
| `dock.scad` 변수 | `pogo_dx = 7.62`, `pogo_y = -L_m/2 + 5`(칸 중심 기준). 띠·고정 보스도 `pogo_y`를 따름 |
| 바닥판 t_f | 3.0(= 공칭 작동 3.70 − 미끄럼 패드 0.4 − 접점 들어감 0.3) |
| 쌓임 | 공칭 3.70, ±0.55 + 홈 가라앉음 0.13 → 3.15~4.38(창 안) |
| 조정 | 칸별 눌린 높이가 3.30~4.20 밖이면 t_f를 0.2 단위로 바꿔 바닥판만 다시 출력 |
| 핀 구멍 | 플랜지 기준 Ø2.25 이상(출력 뒤 실측) |
| 위치 허용 | 팁 중심 ↔ 접점 머리 중심 ≤ 1.215(계산 1.08) |
| 포고 기판 나사 | M2x5 둥근머리 탭핑 칸당 2. 자리는 포켓 안쪽 면 밖·벽 아래, 중심을 안쪽 면에서 ≥ 2 띄움. 띠를 포켓 바로 아래에 박으면 M2x3 탭핑으로 |

## 4. 포켓·방향 키·누름

| 항목 | 값 |
|---|---|
| 포켓 | (L_m + 0.6) × (L_m + 0.6)(L=35면 약 35.6), 깊이 10, 윗 가장자리 1.0 × 45° 모따기. 앞 벽 위 "▼ 접점" 음각 |
| 칸별 포켓 | 큐브 6개 L_m 편차 > 0.15면 칸마다 다르게. 1·2칸 출력 때 기준 L_m을 정하는 규칙 [미정] |
| 방향 키 | 필수. 포켓 한 모서리 키 + 큐브 몸통 대응 모서리. 90°·180°·270°를 모두 막는다. 바닥 돌기 방식은 쓰지 않는다. 형상 [미정] (큐브와 함께) |
| 플런저 구멍 | 포켓 바닥에 내지 않는다. 도크 안에서 S1은 닫혀 있어도 된다 |
| 누름 덮개 | 공통 덮개 1장(PETG 3T) + 칸마다 스펀지 3T 띠 2개(25 × 4) + 긴 변 양 끝 갈고리 2 + 가운데 기둥(x 55·103) 돌림 멈춤쇠 2(각 M3×8) [권장안 U-97] |
| 덮개 위치 | 아랫면 = 포켓 바닥 위 L_h + 1.5(스펀지 1.5 압축). 받침 기둥 6개(Ø8, 칸 사이 교점 2 + 네 모서리)가 하드 스톱 |
| 스펀지 위치 | 큐브 윗면 앞뒤 테(바깥 끝에서 0.75~4.75). 8×8 창(24)은 덮지 않음 |
| 누름 힘 | 목표 칸당 3~4 N, 판정 모든 칸 ≥ 2.2 N(필요 최소 약 1.8 N) |

- 덮개가 필요한 이유: 큐브(약 36 g)는 스스로 핀을 누르지 못한다(핀당 약 10 gf < 예압 15 gf).
- 180°로 넣으면 핀 하나가 큐브 플런저 구멍으로 들어가 S1 과행정을 낼 수 있다. 방향 키를 빼지 않는다.

## 5. 조립과 입력 배선 순서

1. 자르기 전 플러그 단자에서 4.75~5.25 V. 범위 밖이면 자르지 않고 교환 문의. 잰 뒤 AC 코드를 뽑는다.
2. AC 코드를 뽑은 상태에서 플러그 부트 바로 뒤를 자른다.
3. 두 심을 벌리고 AC를 켜 4.75~5.25 V를 다시 재고 + 심을 표시. AC 코드를 뽑고 입력 기판에 납땜.
4. C-D·버스를 잇기 전 입력 기판만으로 극성 확인.
5. 칸마다 PTC → 포고 띠 배선. 칸별 극성 일치, 인접 칸 단락 없음.
6. 첫 전원 전 버스 +–GND 저항(합격 수치 [미정], D-T1 전에 정함).
7. 원통 코어(플러그에서 60~80)는 벽 밖, 벽 안 선 ≤ 약 55. DC 선 홈과 안쪽 케이블타이 자리를 둔다.

## 6. 켜서 확인할 것

| 시험 | 내용 | 합격 |
|---|---|---|
| D-T0 | 포고 치수, 큐브 6개 무게·L_m·L_h, 스펀지 1.5 압축 힘, 덮개 조립 뒤 칸별 누름 힘 | 기록 → `dock.scad` 변수. 모든 칸 ≥ 2.2 N. 눌린 높이 3.30~4.20 |
| D-T1 | 어댑터·칸 극성·무부하 | 자르기 전·납땜 전 4.75~5.25 V, 입력 기판 극성, 버스 저항, 칸별 극성 일치, 인접 칸 단락 없음 |
| D-T2 | 1칸 + 큐브 1개(C6과 함께) | 셀 < 4.0 V 동안 공급 쪽 108~135 mA, < 10 mA로 완충 종료, 정전압 전환 중 끊김 없음, 접점 상승 ≤ 10 ℃. 포고 전압·TP4056 VCC·D2 VF·70~80 mA 지점 VCC−VBAT·충전 시간 기록 |
| D-T3 | 6칸 동시(큐브 6개나 칸당 36 Ω 1 W) + 한 칸 포고 사이 도선 단락 | 전 칸 포고 ≥ 4.45 V(130 mA). 단락 칸 PTC가 10 s 안에 끊고 나머지 칸 충전, 또는 딸꾹질 뒤 단락을 풀면 전 칸 자동 복귀. 포고 변색 없음 |
| D-T4 | 삽입 50회 | 50/50 충전, 접점당 ≤ 0.2 Ω, 7일 방치·충전 반복 뒤 재측정 |
| D-T5 | 90°·180°·270° 오삽입 | 칸 전류 0, 손상 없음, CONTACT_N 기록, S1 과행정·큐브 뜸·핀 휨 없음 |

- 장비: DMM, K형 열전대, 캘리퍼, 주방 저울(0.1~500 g), 36 Ω 1 W × 6.
- 운용: 사람이 있을 때만 충전(밤샘 금지), 불연 바닥, 이상 큐브용 뚜껑 있는 금속 통. 셀이 뜨겁거나 부풀면 먼저 도크 어댑터를 콘센트에서 뽑는다.
- 접점 나사 대체품이 없다. D-T4에서 0.2 Ω을 넘거나 7일 뒤 나빠지면 황동·니켈 일자 접시 M2를 다른 판매처에서 찾는다.

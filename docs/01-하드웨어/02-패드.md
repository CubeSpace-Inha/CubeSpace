# 패드 (PAD Rev B)

이 문서로 답하는 것: 패드를 몇 mm로 만들고, 센서·먹스·LED·전원을 어떻게 배선하고, 어떤 순서로 조립해 켜서 확인하는가.

관련: [01-큐브](01-큐브.md) · [03-도크](03-도크.md) · [04-부품-주문](04-부품-주문.md) · [05-제작-시험-실측값](05-제작-시험-실측값.md) · 펌웨어 동작 [../02-펌웨어/03-패드-프레임-광학.md](../02-펌웨어/03-패드-프레임-광학.md)

- 단위 mm. 기준: 판 형상 1.2절, 배치 좌표 2절, 회로 3~6·8절. 판 3D 파일·배치도·좌표 CSV는 팀 코드 저장소의 생성 스크립트가 이 값으로 다시 만든다.
- 판은 받침 돌기·USB 멈춤턱을 3D 파일에 넣고 T0를 마친 뒤에만 출력한다. 쿠폰은 배선 구멍 Ø3.6/4.0/4.4와 센서 줄 턱 2.9를 넣은 뒤 출력한다.

## 1. 구조·치수

### 1.1 외형과 층

| 항목 | 값 |
|---|---|
| 외형 | 246 × 179 × 40(고무발 포함 약 45) |
| 하판 | 검정 포맥스 3T, 246 × 179, Z 0~3 |
| 하부 공간 | M3 암-암 서포트 10(황동·강철 관통형, 나일론 금지) 6개, Z 3~13 |
| 판 | 3D 프린트 검정 PETG 234 × 167 × 3(안내 턱 0.5 포함 3.5) 한 장, Z 13~16 |
| 광학 공간 | 빈 공간. 끼움 기둥이 상판을 받침. 기본 19, 후보 10·12·15·19 [실측 필요] |
| 상판 | 유백 아크릴 5T, 246 × 179, Z 35~40(광학 공간 19 기준) |
| 측벽 | 검정 포맥스 5T 4장, 높이 32(Z 3~35), 하판에 접착. 안쪽 236 × 169, 판과 둘레 틈 1 |
| 고무발 | 6개, 외곽 x 24·123·222 / y 24·155. 구매품(SparkFun COM-17736) 높이 [실측 필요] |

- 광학 공간이 10·12·15로 정해지면 총 두께 31·33·36이고 측벽 높이를 그에 맞춘다.
- T0에서 하부 부품이 한도(1.3절)를 넘으면 서포트 12 + 광학 공간 ≤ 17로 두께 40을 지킨다 [권장안 U-88].

### 1.2 판 형상

| 요소 | 값 |
|---|---|
| 센서 구멍 | 77개, 시작 Ø3.2(쿠폰 Ø3.0~3.4로 확정). PT204-6B 몸체 Ø3.0 ± 0.2, 플랜지 Ø4.0 × 1.0, 끝이 판 위로 약 1.2 |
| 안내 턱 | 폭 3.1, 높이 0.5. 센서 없는 틈 8줄은 전체 길이, 센서 있는 틈 7줄은 구멍 사이(구멍 중심에서 2.6 띄움) |
| 줄 사이 틈 | 8.33 − 5.0 = 3.33 |
| 배선 구멍 | Ø4.0(AWG20 두 가닥 + 데이터선 외접 3.88), 32개. 각 줄 양 끝, 스트립 끝에서 4(x = 13, 221), y = 그 줄 LED y. 쿠폰으로 확정 |
| 고정 구멍 | Ø3.4, 판 좌표 x 4.5·117·229.5 / y 4.5·162.5(외곽 좌표 = 판 + 6) |
| 끼움 기둥 | 판과 따로 출력. Ø7, 관통 Ø3.4, 높이 10·12·15·19 각 6개 |

| USB 멈춤턱 | 판과 한 몸, x 96~100, y 0.5~9.5, 판 밑면에서 3.1 아래까지 |
| 공차 쿠폰(T0) | 96 × 68 × 3 한 장. 센서 구멍 Ø3.0·3.1·3.2·3.3·3.4(간격 16.667)를 두 줄, 줄마다 구멍 사이 턱 3.1 / 2.9(줄 간격 8.333). 안내 턱 폭 2.9·3.1·3.3을 폭마다 한 쌍(길이 60, 쌍 간격 8.333, 사이에 스트립을 눕혀 봄). 배선 구멍 Ø3.6·4.0·4.4(턱 끝에서 4). 값을 글자로 새김. 쿠폰 안 배치는 가정 |

출력: 검정 PETG, 노즐 0.4, 평판 면을 바닥으로, 서포트 없음.

### 1.5 외함 홈·체결

- 뒷벽 U자 홈(위 트임) 2개
  - USB: 폭 약 15(판 x 약 8.5~23.5), 바닥 Z 3. ㄱ자 케이블 Qualtek 3021107-01M을 안에서 Zero에 꽂아 −y로 뺀다. 머리는 안쪽에서 케이블타이로 하판에 묶는다. 바깥으로 단단한 몸체 약 6.0, 보호부 끝 약 15.0 나온다.
  - DC: 폭 = DC 선 외경 실측 + 0.5, 중심 외곽 x 184(판 x 178), 바닥 Z 3. 안쪽 케이블타이로 당김 고정.
- 체결: 위 = 상판 접시 M3 → 끼움 기둥 → 판 → 서포트, 아래 = M3 둥근머리 → 서포트. 상판 접시 자리는 미리 파지 않고 도착 나사 머리가 면과 같아질 때까지만 판다. 아래 나사를 먼저 박는다.

| 광학 공간 | 총 두께 | 위(접시) | 아래(둥근) | 위 물림 / 아래 물림 / 끝 여유 |
|---:|---:|---|---|---|
| 10 | 31 | M3×25 | M3×5 | 7 / 2 / 1 |
| 12 | 33 | M3×25 | M3×6 | 5 / 3 / 2 |
| 15 | 36 | M3×30 | M3×5 | 7 / 2 / 1 |
| 19 | 40 | M3×30 | M3×8 | 3 / 5 / 2 |

M3×5가 없으면 M3×6 + 평와셔. 확정 조립 전에 상판·기둥 실측으로 다시 계산한다.

## 2. 좌표계

- 판 좌표: 원점 = 판 뒤 왼쪽 모서리, X 오른쪽, Y 사용자 쪽. 외곽 좌표 = 판 좌표 + 6.
- 조작(LED) 영역 좌표 = 판 좌표 − (17.00, 16.83). 범위 x 0~200, y 0~133.33. PC가 쓰는 좌표다.

| 요소 | 식(판 좌표) | 범위 |
|---|---|---|
| LED 영역 | x 17~217, y 16.83~150.17 | 200 × 133.33 (3:2) |
| LED 열 x (24열, 피치 8.333) | 117 + (i − 11.5) × 8.333, i = 0~23 | 21.17 ~ 212.83 |
| LED 줄 y (16줄, 피치 8.333) | 83.5 + (k − 7.5) × 8.333, k = 0~15 | 21.0 ~ 146.0 |
| 스트립 | 줄마다 x 17 ~ 217, 폭 5 | |
| 센서 열 x (11열, 간격 16.667) | 117 + (c − 5) × 16.667, c = 0~10 | 33.67 ~ 200.33 |
| 센서 행 y (7행) | 33.5 + 16.667r, r = 0~6 | 33.5 ~ 133.5 |

- 모든 센서가 LED 4개의 정중앙이다. 35 큐브가 LED 영역 안이면 빛점은 x 34.5~199.5, y 34.33~132.67로 늘 센서로 둘러싸인다.
- 피치는 정확히 1000/120(= 8.3333…), 센서 간격은 그 2배다. 이 값으로 위 식을 계산해 소수 둘째 자리로 반올림하면 아래 배치 CSV 두 개와 모든 행이 같다.
- LED 좌표 CSV 384행: 데이터선 = ⌊(줄 − 1)/4⌋(0~3), 체인번호 = ((줄 − 1) mod 4) × 24 + (홀수 줄이면 열 − 1, 짝수 줄이면 24 − 열)(0~95), 줄 1~16(= k + 1), 열 1~24(= i + 1), x, y.
- 구멍 좌표 CSV 115행(종류, ID, 행, 열, x, y, 지름, 먹스, 채널):
  - 센서 77: ID `S행-C열`(`S1-C1`~`S7-C11`, 행 = r + 1, 열 = c + 1), Ø3.2, 먹스 = 행 − 1, 채널 = 열 − 1.
  - 기둥 6: `P1`~`P3` = (4.5·117·229.5, 4.5), `P4`~`P6` = (4.5·117·229.5, 162.5). 지름 칸은 기둥 바깥 Ø7.0(판 구멍은 Ø3.4).
  - 배선 32: `W줄L`·`W줄R`(줄 1~16), x 13 / 221, y = 그 줄 LED y, Ø4.0.
- 스트립 실측 피치가 8.33이 아니면(24개 폭 S가 190.7~192.7 밖) 가로 = S/23, 세로 8.33으로 LED CSV·UI 격자만 다시 만든다 [권장안 U-87]. 판·센서 좌표는 그대로.

## 3. 광센서 판독 회로

```
+3V3S ─ 행 모선(주석선 Ø0.6) ─ 컬렉터 [PT204-6B × 11] 이미터 ─ AWG30 ─ 먹스 Mr ch0~10
                                                       ch11~14 비움, ch15 ─ GND(영점)
Mr SIG ─┬─ Zero ADC1 핀
        ├─ RLr ─ GND
        └─ CFr ─ GND        (RL·CF는 제어 기판, Zero 가까이)
```

| 항목 | 값 |
|---|---|
| 센서 | Everlight PT204-6B 77개, 한 로트. 긴 다리 = 이미터, 짧은 다리 = 컬렉터. 켜짐 전류 등급 편차 최대 7배라 몸체·이득 선별 |
| RL | 시작 4.7 kΩ. 후보 470 Ω · 1 · 2.2 · 4.7 · 10 kΩ(+ 직렬용 220 Ω), 하한 470 Ω. 기둥 높이마다 측정으로 고름 [실측 필요]. 후보 범위는 권장안이고, 처음 설계값은 RL 4.7 kΩ이다 |
| CF | X7R. RL × CF ≤ 47 µs: 10 nF(RL ≤ 4.7 kΩ), 1 nF(RL ≤ 10 kΩ), 100 nF는 RL ≤ 470 Ω만 |
| ADC | Zero ADC1(GPIO1~10), 6 dB 감쇠, 유효 0~1600 mV, 총 오차 ±10 mV. 12 dB 쓰지 않음 |
| 포화 기준 SAT_MV | min(1550, V_clip − 50) mV, 시작 1550. V_clip은 PT-1s로 잼(≤ 2.0 V) |
| 신호 목표 | 가장 밝은 조건의 최대 ≤ 1500 mV, 가장 어두운 센서 V_bot ≥ 500 mV, 배경 ≤ 0.3 V_REF. 권장안이고, 처음 설계값은 T1 최대 0.6~1.4 V다 |
| 동시 전류 | 7개, 개당 ≤ 0.7 mA(RL 4.7 kΩ) |

- 신호가 너무 세서 RL < 470 Ω이 필요하면 큐브 R1을 47 → 100 → 220 Ω으로 올린다(6대 같은 값).
- 차광 벽 없음. LED 빛 누설이 T4(T4a·T4b)에서 보이면 센서 둘레에 출력 차광 링(높이 2)을 더한다.
- 스캔·판정·보정은 펌웨어·광학 문서 몫이다.

## 4. 먹스 배선

| 먹스 | 센서 행 | SIG → Zero | 채널 |
|---|---|---|---|
| M0 | r = 0 (y 33.5) | GPIO1 | ch k = 센서 열 k (k = 0~10) |
| M1 | 1 | GPIO2 | 〃 |
| M2 | 2 | GPIO4 | 〃 |
| M3 | 3 | GPIO5 | 〃 |
| M4 | 4 | GPIO6 | 〃 |
| M5 | 5 | GPIO7 | 〃 |
| M6 | 6 (y 133.5) | GPIO8 | 〃 |

- 공통: S0~S3 = GPIO11~14(7개 공유), EN = GND, ch11~14 비움, ch15 = GND.
- 모듈: VLT-VC075(칩 HP4067, 약 40.6 × 17.8 × 3.6). 도착 검사: 칩 표기 HP4067(HCT형이면 교환), EN–GND 약 10 kΩ, SIG–GND 개방(SIG에 10 kΩ이 있으면 제거), 두께 ≤ 5.5.
- 전원: 먹스 VCC = 3V3M. +3V3S(Zero 3V3) ─ RF 10 Ω ─ 3V3M, C-MB 100 µF + C-MF 100 nF(3V3M–GND), 먹스마다 CMr 100 nF. 센서 행 모선은 +3V3S 직결.
- 선: 이미터 개별선 AWG30 단심 77가닥(길이 10~110, 5열마다 색 바꿈). SIG 7가닥은 GND선과 묶어 x 약 92로 제어 기판 앞 가장자리(y 26.5)까지. 주소 4 + GND도 같은 길.

## 5. LED 스트립·체인·급전

### 5.1 스트립

| 항목 | 값 |
|---|---|
| 제품 | ANTVLED WS2812B계 5 V, 120 LED/m, 폭 5, IP30, RGB 3색 칩. 5 m 롤 1개(필요 3.2 m) |
| 배치 | 24 × 16 = 384개. 줄마다 24개(x 17~217) |
| 부착 | 센서를 먼저 꽂고, 스트립은 센서 반대쪽 안내 턱에 붙인다 |
| 칩 확인 | RGBW면 W = 0(재주문 없음, T9 재판정). IR 겸용·형광체 흰색 단색이면 재주문 |

### 5.2 데이터 체인

| 체인 | 줄 | Zero GPIO | AHCT125N (A 입력 / Y 출력 / OE 핀) | 직렬·풀다운 |
|---|---|---|---|---|
| 0 | 1~4 | 15 | 2 / 3 / 1 | RD0 330 Ω, RP0 100 kΩ(입력–GND), RPD0 10 kΩ(DIN–GND) |
| 1 | 5~8 | 16 | 5 / 6 / 4 | RD1·RP1·RPD1 같은 값 |
| 2 | 9~12 | 17 | 9 / 8 / 10 | RD2·RP2·RPD2 |
| 3 | 13~16 | 18 | 12 / 11 / 13 | RD3·RP3·RPD3 |

- AHCT125N: VCC 14번 = +5V_LED(AWG20 전용선), GND 7번, C-U2 100 nF. OE 4개는 OE_N 하나로 묶고 RE3 10 kΩ으로 +5V_LED 풀업.
- 체인마다 시작은 왼쪽 끝(배선 구멍 x 13, 줄 1·5·9·13)이고 지그재그다(홀수 줄 왼→오, 짝수 줄 오→왼). 줄 사이 DOUT→DIN은 데이터 점퍼(AWG26).
- 데이터 4가닥 + GND: 제어 기판 앞 가장자리 → y 27~31 통로 → 왼쪽 띠(x < 31.7) → 체인 시작 구멍. 센서선과 떨어뜨린다.

### 5.3 급전 배선

| 구간 | 도체 | 설계 최대 |
|---|---|---|
| 어댑터 DC 선 → 입력 기판 | 어댑터 부속 16 AWG(플러그 잘라 직결) | 4 A |
| 입력 기판 → 오른쪽 모선 뒤 끝 | 18 AWG +/−, 0.04 m | 4 A |
| 좌우 모선(x 5·229), 앞쪽 가로선(y 약 157) | 18 AWG +/− | 한쪽 2 A |
| 줄 끝 가지선 | UL1007 AWG20, 64가닥 | 0.72 A |
| 버퍼 VCC·GND | AWG20 한 쌍, y 10~14 통로 | < 0.05 A |
| OE_N → R_G | AWG26 | < 1 mA |
| 데이터 | AWG24~26 | mA |

- 규칙: 어댑터 뒤 모든 전력 도체는 섀시 허용 ≥ 9 A(어댑터 딸꾹질 문턱 상한).
- 16줄 모두 양 끝 급전. 경로: 입력 기판 → 오른쪽 모선 → 앞쪽 가로선 → 왼쪽 모선.
- 줄 끝 접합 방식 [미정]: T0 조각 시험으로 (가) 30 이하 AWG24~26 가는 선 경유 (나) AWG20 직접 (다) 한 LED 안쪽 온전한 패드에 +·G 가운데 고른다. (다)면 판 출력 전 배선 구멍 위치를 다시 본다. 시한은 16줄 본 절단 전.
- 줄 끝 납땜: AWG20 세 선을 반쪽 패드에 나란히 눕히지 않는다. 선을 먼저 고정해 패드에 당김이 없게, 예비 납땜 후 플럭스로 짧게 가열.
- 가지선 전에 줄마다 인쇄 +5V/GND와 모선 색을 대조한다.

## 6. 전원 경로

```
어댑터 GST60A05-P1J DC 선(16 AWG)
  ─ Q-P4 D … S ─ +5V_LED ─┬─ C-P1a·b 470 µF × 2 ─ GND,  RB 4.7 kΩ ─ GND
     G ─ R_G4 100 kΩ ─ GND  ├─ AHCT125 VCC(AWG20), C-U2, RA1, RE3
                           └─ Q-P3 S … D ─ +5V_STRIP ─ 18 AWG 모선 ─ 16줄 양 끝
                                 G ─ R_G 100 kΩ ─ OE_N
Zero 3V3(+3V3S) ─ RA3 10 kΩ ─ ADAPTER_N(GPIO38) ─ Q-P1 C;  +5V_LED ─ RA1 47 kΩ ─ Q-P1 B, RA2 100 kΩ B–GND
GPIO40 LED_EN ─ RE1 10 kΩ ─ Q-P2 B, RE2 100 kΩ B–GND;  Q-P2 C ─ OE_N
```

| 부품 | 값 | 역할 |
|---|---|---|
| PS-P | Mean Well GST60A05-P1J, 5 V 6 A급, ±5 %, 과부하 딸꾹질 6.3~9 A | LED 전원. 잭·퓨즈 없이 DC 선 직결 [권장안 U-05] |
| Q-P4 | NTMS10P02R2G(SOIC-8, Adafruit 1212 위) | 입력 직렬 역극성 보호. D(5~8) = 어댑터 +, S(1·2·3) = +5V_LED, G(4) = 100 kΩ → GND [권장안 U-12] |
| Q-P3 | NTMS10P02R2G(1212 위) | LED 전원 차단. S = +5V_LED, D = +5V_STRIP, G = R_G → OE_N [권장안 U-12] |
| Q-P1·Q-P2 | MMBT3904 | 어댑터 감지 / 출력 허용 |
| C-P1a·b | 470 µF 16 V 삼영 KMG 8 × 11.5 | +5V_LED 저장 |
| RB | 4.7 kΩ | 방전. 어댑터만 있을 때 입력 ≤ 5 mA의 대부분 |

- 동작: LED_EN HIGH → Q-P2가 OE_N을 LOW로 → 버퍼 출력 허용 + Q-P3 켜짐. LED_EN LOW·Zero 꺼짐 → 버퍼 고임피던스, Q-P3 꺼짐, 첫 DIN은 RPD로 GND.
- ADAPTER_N LOW = 어댑터 있음. 전압 판정이 아니라 존재 감지다.
- 두 FET 모두 1212의 S·D 패드 바깥 끝을 AWG18 또는 UL1007 AWG20으로 묶어 입력 기판 단자에 직결한다(트레이스 우회 필수, 안 하면 V_in 4.49~4.52 V로 미달 가능). 1212 패드에 안 들어가면 방법 [미정].
- 칩 쪽 S 패드끼리·D 패드끼리 땜납으로 잇는다. 굵은 선은 기판 패드에 잇고 케이블타이로 당김을 막는다. SOIC 다리에 굵은 선을 직접 달지 않는다.
- 제어부·센서는 PC USB(Zero LDO ME6217, 최대 800 mA). USB 5 V와 +5V_LED의 +극은 잇지 않고 GND만 제어 기판 한 점에서 잇는다.
- 원통 코어(플러그에서 60~80)는 벽 밖. 벽 안 선 길이(DC 홈~입력 기판) 약 55 이하.

## 10. 켜서 확인할 것

### 10.1 T12 0행: 입력 기판 단계 (스트립·제어 기판 전)

1. Q-P4 방향: 다이오드 모드로 빨강 D(어댑터 + 단자), 검정 S(+5V_LED)에서 순방향 전압, 바꿔 대면 OL. G–GND ≈ 100 kΩ, G–S 단락 없음.
2. 자르기 전 플러그 단자 무부하 4.75~5.25 V. 범위 밖이면 자르지 않고 교환 문의. 잰 뒤 AC 코드를 뽑는다.
3. AC 코드를 뽑은 상태에서 플러그 부트 바로 뒤를 자른다.
4. 두 심을 벌리고 AC를 켜 4.75~5.25 V를 재고 + 심을 표시한다.
5. 선 끝 딸꾹질 복구: 납땜 전 DC 선 끝 두 심을 AWG18 이상으로 짧게 단락 → 풀면 AC를 다시 꽂지 않고 4.75~5.25 V로 돌아와야 한다. 단락 시간·복귀 대기 상한 [미정]. **입력 기판 +5V_LED에서는 단락하지 않는다**(Q-P4 손상).
6. AC 코드를 뽑고 입력 기판에 납땜한다.
7. (a) +5V_LED–GND ≥ 1 kΩ(정상 4 kΩ대, 940 µF 충전 뒤 안정값).
8. 첫 전원(어댑터만) Q-P4 D–S < 50 mV. 0.3 V 이상이면 몸체 다이오드 도통이니 부하를 잇지 않는다. 어댑터를 납땜한 뒤에는 벤치 전원을 어디에도 잇지 않는다.

- 자리를 비울 때는 AC 코드를 뽑는다.

| 밝기 상한 | 시험 밝기 32/255(키 9는 한 줄 패턴에서만 255). I_est = 384 × 2.5 mA + 켠 LED 수 × (R + G + B) × 20 mA / 255가 4.0 A를 넘는 프레임은 보내지 않고 "BLOCKED"를 찍음 |
| 키 | p 패턴(검정 → 체인별 첫 LED → 체인별 한 줄 → 전체), c 색 W·R·G·B, 9 한 줄 255, l 전체 켜기·끄기(T4), o 검정 + LED_EN LOW(T12), h 펌웨어 정지(감시 타이머로 약 5 s 뒤 재부팅, T12 7행), + / − 대기 ±50 µs(T5), z 자가진단 |

# 큐브 (CB-35 Rev E)

이 문서로 답하는 것: 큐브 한 대를 무엇으로, 어떻게 배선하고, 어떤 크기로 출력해 조립하고, 켜서 무엇을 보면 되는가.

관련: [02-패드](02-패드.md) · [03-도크](03-도크.md) · [04-부품-주문](04-부품-주문.md) · [05-제작-시험-실측값](05-제작-시험-실측값.md) · 펌웨어 동작 [../02-펌웨어/02-큐브.md](../02-펌웨어/02-큐브.md)

- 단위 mm. 좌표 원점은 큐브 바깥 앞-왼쪽 모서리의 패드 조작면(미끄럼 패드 접촉면). X 오른쪽, Y 뒤, Z 위.
- 제작 수단: 3D 프린터(PETG) + 손납땜. PCB 외주 없음. 자작 기판은 A2 한 장뿐이다.
- 기준: 회로는 2·3절, 치수는 4절(값 4.5절, 여유 검사 4.6절), A2 납땜 자리와 배선은 부록. 외함 STL·도면·A2 표는 팀 코드 저장소의 생성 스크립트가 이 값으로 다시 만든다.

## 2. 회로 연결

### 2.1 전원 경로

```
충전:    도크 +5V ─ P1(DOCK_RAW) ─ D2 ─ DOCK5V ─ U1 IN+      P2 ─ GND
셀:      B1 ─ J-BAT ─ U1 B+/B−                                U1 IN−·OUT− ─ GND
전원 문: U1 OUT+(VBAT) ─ Q2 S,  Q2 D ─ V_A1 ─ A1 "5V" 패드,  C4 V_A1–GND
게이트:  VBAT ─ R9 100k ─ Q2 G(PWR_GATE)                       평소 닫힘
  ① 버튼:   PWR_GATE ─ D3 ─ BTN ─ SW2 ─ GND
  ②③ Q3:   PWR_GATE ─ Q3 C,  Q3 E ─ GND
Q3 베이스: ② DOCK5V ─ C3 10µ ─ R12 100k ─ Q3_B          (도크에 닿은 직후 약 1 s)
           ③ GPIO6 PWR_HOLD ─ D6 ─ R10 10k ─ Q3_B        (펌웨어가 잡는 동안)
           R11 100k Q3_B–GND,  D4 (A = GND, K = Q3_B)
```

- 배터리 직결, 승압기 없음. V_A1은 승압된 5 V가 아니라 배터리 전압(3.6~4.2 V)이다.
- 문을 여는 것은 ① SW2 누름 ② 도크 펄스 ③ PWR_HOLD HIGH. 끄는 것은 PWR_HOLD LOW 하나다. 동작 순서는 펌웨어 문서 몫이다.
- U1 CHRG는 연결하지 않는다. A1 3V3 패드로 별도 급전하지 않는다(ME6217은 VOUT > VIN + 0.3 V 금지).
- 도크 위에서는 큐브가 반드시 꺼진 채 충전된다. TP4056은 전원 경로 분리가 없어 LED 대기 전류가 있으면 완충 종료를 못 한다.

### 2.2 신호 회로

| 기능 | 연결 |
|---|---|
| IR 구동 | 3V3 ─ R1 47 Ω ─ D1 애노드, D1 캐소드 ─ Q1 C, Q1 E ─ GND. GPIO1 ─ R2 1 kΩ ─ Q1 B, R3 100 kΩ B–GND. 약 41 mA(최악 31~49 mA) |
| S1 접촉 | S1 NO ─ CONTACT_N(GPIO2), S1 COM ─ GND, NC 비움. R8 10 kΩ CONTACT_N–3V3, C1 10 nF CONTACT_N–GND. LOW = 놓임 |
| 버튼 읽기 | GPIO7 BTN_N ─ D5(A = BTN_N, K = BTN) ─ SW2 ─ GND. 내부 풀업. LOW = 눌림 |
| 도크 감지 | DOCK5V ─ R13 47 kΩ ─ Q4 B, R14 100 kΩ B–GND. Q4 C ─ DOCK_N(GPIO5), R15 10 kΩ DOCK_N–3V3, Q4 E ─ GND. LOW = 도크 위. 꺼진 A1 핀에 전압이 걸리지 않는다 |
| 배터리 분압 | V_A1 ─ R4 200 kΩ ─ VBAT_ADC(GPIO4) ─ R5 100 kΩ ─ GND, C2 100 nF VBAT_ADC–GND. 1/3, 4.2 V → 1.4 V. Q2 뒤라 꺼져 있으면 전류 0 |
| 8×8 LED | A1 내장. 전원 V_A1, 데이터 GPIO14(보드 레벨시프터) |

- R1 사다리: 22 / 47 / 100 / 220 Ω → 84 / 41 / 20 / 9 mA. 6대 모두 같은 값. 22 Ω을 쓰면 R2를 470 Ω으로 바꾼다. 값은 패드 광학 시험으로 정한다([05](05-제작-시험-실측값.md) 2절).

### 2.3 도크 접점

- P1 = +(DOCK_RAW), P2 = GND. 좌표는 4.3절.
- 나사 머리 윗면 = 바닥면에서 0.3 ± 0.15 들어감. 접점 저항 ≤ 0.2 Ω.
- 전선 고리는 뚜껑에 끼우기 전 너트 윗면에 미리 납땜한다(니켈이라 활성 플럭스). 나사 고정제는 너트 윗면 위 나사 끝에만 소량, PETG에 닿지 않게.

## 4. 치수·외함

### 4.1 35/40 판정

- 한 변 L = 35로 먼저 만들고, 안 되면 최대 40. 벽 1.5, 모서리 R3, 안쪽 32×32.
- **판정 결과: 아직 없음(실측 전). 현재 출력 기준은 L = 35다.**
- 판정 입력 [권장안 U-55]. 모두 35에서 통과하면 35, 35 실패·40 통과면 40. 최종은 실측값을 넣은 여유 검사(4.6절) ≥ 0.3.

| J | 입력 | L=35 통과 | L=40 통과 | 시험 |
|---|---|---|---|---|
| J1 | U1 W·D(USB-C 제거 뒤) | W ≤ 26.3, D ≤ 17.29 | W ≤ 26.3(뚜껑 기둥이면 28.9), D ≤ 19.79 | CT-1M |
| J2 | A1 전체 높이 A1_H | ≤ 8.7 | ≤ 13.7 | CT-1M |
| J3 | J-BAT 결합 쌍 | 결합 길이 + 위 S자 + 아래 U턴 + 0.3×2 ≤ 12.65 | 같음 | CT-1M |
| J4 | S1 자중 | 1.2 × max(F_op, F_full) ≤ F_avail인 S1 ≥ 8 | 같은 식(L=40) | CT-12a·b |
| J5 | 셀 용량 | 연속 사용 ≥ T_REQ | 셀 폭 ≤ 25, 두께 ≤ 6.0 + (13.7 − A1_H) | C1, C7 |
| J6 | 셀 Y | L_cell + R_lead ≤ 31.4 | ≤ 36.4 | B1-A, CT-1M |

- 40에서도 실패: J1 모듈 교체, J3 결합 쌍 자리 재설계(눕히는 대안은 권하지 않음, CT-1M 실측 뒤 정함), J4 [권장안 U-86] (통과 S1만 쓰고 재주문 → 8개 미만이면 L=40 + 추), J5·J6 셀 변경 [권장안 U-03], J2는 A1 교체 검토.
- L=40으로 바꿀 때는 L을 40.0으로 바꾸고 STL을 다시 만든다. 미리 만들어 둔 L=40 STL을 바로 출력하지 않는다.

## 6. 안전 규칙

1. A1 USB-C를 꽂기 전에 J-BAT를 뽑는다. Q2가 꺼져 있어도 Matrix 보드 D1(B5819WS)과 Q2 몸체 다이오드로 USB 5 V가 셀에 제한 없이 흐른다(0~1.67 A). USB를 뺀 뒤에만 다시 꽂는다. USB 중 뽑아 둔 J-BAT 핀에 최대 약 4.9 V가 나오니 금속에 닿지 않게 한다.
2. Matrix D1을 각 큐브 조립 직전에 뗀다 [권장안 U-58]. 1호기 V-USB 통과 뒤 나머지. 버리는 보드로 SOD-323 제거를 먼저 연습한다. D1이 붙은 A1은 규칙 1을 따르고, 개발용 예비 A1에는 셀·벤치 전원을 잇지 않는다. Matrix D1과 A2의 D1(IR LED)은 다른 부품이다.
3. 셀 모델이 정해지고 130 mA 허용을 확인하기 전에는 충전 시험(C6)을 하지 않는다. U1-B·C6 통과 전에는 큐브를 도크에 넣지 않는다.
4. 납땜은 셀을 분리하고 한다. 셀은 누르거나 구부리지 않고 트레이 안에 둔다.
5. J-BAT 극성: 셀과 결합한 채 리드 끝 전압으로 +를 찾아 표시(두 끝이 닿지 않게) → 셀에서 뽑음 → 한 가닥씩 벗겨 U1 B+/B−에 납땜 → 첫 연결 전 극성 재측정. 셀 리드·커넥터는 자르지 않는다.
6. 첫 통전은 전류 제한 벤치 전원으로 한다. 벤치를 J_OUTP에 물린 동안 도크 5 V를 넣지 않는다(U1이 벤치를 거꾸로 충전).
7. 충전은 큐브를 끄고 사람이 있을 때만, 밤샘 금지.

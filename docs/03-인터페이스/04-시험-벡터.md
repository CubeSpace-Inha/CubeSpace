## 가상 광학과 정상 가정 (선개발 공용)

하드웨어 전에 펌웨어 `sim_pad`와 PC `--source=sim`이 같은 OBS 값을 만들도록 둘 다 아래 모형·값을 쓴다. 좌표·세션 흐름을 맞춰 보는 용도이고 합격 근거가 아니다(실물 값은 보정 뒤 `cal-<serial>.json`).

빛 모형(유백 상판의 고른 확산 빛점 가정. 상판이 투명으로 바뀌면 실물과 다를 수 있다 [실측 필요]):

```
센서 (r, c) 값 mV = VPK × R(px − SX[c], py − SY[r])     SX = 33.67 + (50/3)c, SY = 33.5 + (50/3)r (패드 판 좌표, 50/3을 반올림하지 않음)
f(dx, dy) = (1 + (dx² + dy²) / H²) ^ (−(3 + m) / 2)
k_i = σ × (i − 3) × 2/3,  w_i = exp(−(k_i/σ)² / 2),  i = 0~6        (σ = 0이면 k = 0, w = 1 한 점)
R(dx, dy) = Σ_i Σ_j w_i w_j f(dx + k_i, dy + k_j) / Σ_i Σ_j w_i w_j f(k_i, k_j)
```

| 값 | 선개발 기준 |
|---|---|
| 모형 | H = 17.8 mm(광학 공간 19), m = 1, σ = 4 mm, VPK = 1000 mV, 배경 0, 잡음 0(견딤 시험만 5 mV 정규 잡음) |
| `cal-sim.json` | `gain` 모두 1, `bad` 없음, `offset_mm` 0, `th_on_mv` 100 × 6, `curve` = 같은 모형으로 만든 401점 표 둘. `u·t`는 빛점을 센서 (3, 5)에서 x로 t ∈ [−1, 1] 옮기며 3 × 3 중심 고정 창의 u(`curve()`), `edge_u·edge_t`는 끝 센서 (0, 5)에서 안쪽으로 t ∈ [0, 1] 옮기며 2 × 3 창의 안쪽 줄 비(`curve_edge()`) |
| 패드 | `frame_us` 50000, `bad_map` 0, STATUS `flags` b1 = 1·b2 = 1 |
| 연결 정상 | 등록 슬롯마다 LINK `up=1`·`reason 0`, EVT HELLO `v0 = 1`, EVT SYNC `v0 = 1`, OBS `st` b2 = 1. 끊김·재연결은 넣지 않음 |
| 배터리 정상 | EVT BATT `v1 = 3900` mV 고정, BYE 3 없음 |

| 합격(잡음 0) | 기준 |
|---|---|
| 정지 | 큐브 위치마다 estimate 좌표와 참값 차 ≤ 1.0 mm(모형 최대 0.66, 가장자리 두 줄 축에서) |
| 이동 200 mm/s | 프레임마다 차 p95 ≤ 0.5 mm(모형 p95 0.26, 추적 창 3 × 4 + [소프트웨어 02](../04-소프트웨어/02-게이트웨이-좌표.md) 5절 4단계) |
| 세션 | 부팅 열: HELLO → 슬롯별 LINK `up=1` → EVT HELLO·CONTACT·BATT → STATUS, 그 뒤 슬롯마다 프레임당 OBS 1개(`frame_no` 연속) |

정지·이동 두 기준은 아래 부록 코드를 실행해 확인한다.

## 부록: 빛 모형과 좌표 추정 기준 구현

PC `estimate`([소프트웨어 02](../04-소프트웨어/02-게이트웨이-좌표.md) 5절)와 펌웨어 가상 패드가 따를 기준 코드다(Python 3.10 이상 + numpy). `curve()`·`curve_edge()`가 `cal-sim.json`의 두 곡선 표를, `track_window()`가 펌웨어 추적 창 위치(펌웨어 03 6.4)를 만든다. 파일로 저장해 실행하면 위 합격 기준을 assert한다(Windows는 `py`).

```python
"""빛 모형과 좌표 추정 기준 구현(시험 벡터 문서 부록). numpy만 쓴다.
PC estimate는 이 estimate()와 같은 창·같은 표로 좌표 차 ≤ 0.01 mm여야 한다.
실행하면 선개발 합격 기준(정지 최대 ≤ 1.0 mm, 200 mm/s p95 ≤ 0.5 mm)을 확인한다.
"""
import numpy as np

PITCH = 50 / 3                          # 센서 간격 mm
SX = 33.67 + PITCH * np.arange(11)      # 센서 열 x(패드 판 좌표)
SY = 33.5 + PITCH * np.arange(7)        # 센서 행 y
SPOT_X, SPOT_Y = (34.5, 199.5), (34.33, 132.67)   # 큐브 몸체가 LED 영역 안일 때 빛점 범위
H19 = 17.8                              # 광학 공간 19 mm일 때 센서 끝~상판 아랫면


def response(px, py, h, m, blur):
    """빛점 (px,py) N개 → 센서 7×11 신호(센서 바로 위 = 1)."""
    k = np.linspace(-2, 2, 7) * blur if blur else np.zeros(1)
    w = np.exp(-0.5 * (k / blur) ** 2) if blur else np.ones(1)
    f = lambda dx, dy: (1 + (dx**2 + dy**2) / h**2) ** (-(3 + m) / 2)
    out, ref = 0, 0
    for ox, wx in zip(k, w):
        for oy, wy in zip(k, w):
            dx = px[:, None, None] + ox - SX[None, None, :]
            dy = py[:, None, None] + oy - SY[None, :, None]
            out = out + wx * wy * f(dx, dy)
            ref = ref + wx * wy * f(ox, oy)
    return out / ref


def centroid(v, fixed=None):
    """가장 센 센서 주변 3×3(격자 안으로 당김) 가중 중심. → 창 중심 (x,y), 치우침 u (간격 단위)."""
    n = len(v)
    r, c = np.unravel_index(v.reshape(n, -1).argmax(1), v.shape[1:])
    r, c = r.clip(1, 5), c.clip(1, 9)
    if fixed:
        r, c = np.full(n, fixed[0]), np.full(n, fixed[1])
    i = np.arange(n)[:, None, None]
    win = v[i, (r[:, None] + [-1, 0, 1])[:, :, None], (c[:, None] + [-1, 0, 1])[:, None, :]].clip(0)
    s = win.sum((1, 2))
    ux = (win.sum(1) @ [-1, 0, 1]) / s
    uy = (win.sum(2) @ [-1, 0, 1]) / s
    return SX[c], SY[r], ux, uy


def curve(h, m, blur):
    """보정 곡선: 잡음 없는 모형에서 한 축으로 빛점을 옮기며 u(t)를 구해 뒤집는다.
    ponytail: 다른 축 위치를 무시한 1차원 곡선. 잔차가 크면 2차원 표로."""
    t = np.linspace(-1, 1, 401)
    _, _, u, _ = centroid(response(SX[5] + t * PITCH, np.full(401, SY[3]), h, m, blur), fixed=(3, 5))
    assert (np.diff(u) > 0).all()
    return u, t


def curve_edge(h, m, blur):
    """가장자리 곡선: 바깥에 센서가 없는 끝 줄. 빛점을 끝 센서(행 0)에서 안쪽 행 1까지 옮기며 u = 안쪽 줄 / 합."""
    t = np.linspace(0, 1, 401)
    v = response(np.full(401, SX[5]), SY[0] + t * PITCH, h, m, blur)[:, 0:2, 4:7].clip(0)
    u = v[:, 1].sum(1) / v.sum((1, 2))
    assert (np.diff(u) > 0).all()
    return u, t


def track_window(v):
    """펌웨어 추적 창 3행 × 4열 위치(펌웨어 03 6.4). v = 직전 프레임 7×11 값."""
    r, c = np.unravel_index(v.argmax(), v.shape)
    right = v[r, c + 1] if c < 10 else -np.inf
    left = v[r, c - 1] if c > 0 else -np.inf
    return int(np.clip(r - 1, 0, 4)), int(np.clip(c - 1 if right >= left else c - 2, 0, 7)), 3, 4


def estimate(v, win, u_t, u_e):
    """좌표 추정 기준 구현(소프트웨어 02 5절 4~6단계). v = 7×11 값, win = (r0, c0, h, w), 반환 = 패드 판 좌표.
    축마다: 창 안 최댓값이 격자 끝 줄이면 있는 두 줄 + 가장자리 곡선, 아니면 창 안쪽으로 민 세 줄 + 대칭 곡선."""
    r0, c0, hh, ww = win
    sub = v[r0:r0 + hh, c0:c0 + ww]
    r, c = np.unravel_index(sub.argmax(), sub.shape)

    def lines(i, lo, n, last):
        if i in (0, last):
            return ([0, 1] if i == 0 else [last - 1, last]), i
        k = int(np.clip(i, lo + 1, lo + n - 2))
        return [k - 1, k, k + 1], k

    rows, rc = lines(r + r0, r0, hh, 6)
    cols, cc = lines(c + c0, c0, ww, 10)
    w = v[np.ix_(rows, cols)].clip(0)
    s = w.sum()

    def t_of(sums, k):
        if len(sums) == 2:
            return np.interp(sums[1] / s, *u_e) if k == 0 else -np.interp(sums[0] / s, *u_e)
        return np.interp((sums[2] - sums[0]) / s, *u_t)

    return SX[cc] + PITCH * t_of(w.sum(0), cc), SY[rc] + PITCH * t_of(w.sum(1), rc)


def check_estimate(h, m, blur, n=2000):
    """선개발 가상 광학(시험 벡터 문서)의 합격 기준: 잡음 0에서 정지 최대 ≤ 1.0 mm, 200 mm/s p95 ≤ 0.5 mm."""
    u_t, u_e = curve(h, m, blur), curve_edge(h, m, blur)
    g = np.random.default_rng(7)
    px, py = g.uniform(*SPOT_X, n), g.uniform(*SPOT_Y, n)
    a = g.uniform(0, 2 * np.pi, n)
    qx, qy = (px + 10 * np.cos(a)).clip(*SPOT_X), (py + 10 * np.sin(a)).clip(*SPOT_Y)   # 200 mm/s × 50 ms
    vp, vq = response(px, py, h, m, blur), response(qx, qy, h, m, blur)
    still = [np.hypot(*(np.subtract(estimate(vp[i], track_window(vp[i]), u_t, u_e), (px[i], py[i])))) for i in range(n)]
    move = [np.hypot(*(np.subtract(estimate(vq[i], track_window(vp[i]), u_t, u_e), (qx[i], qy[i])))) for i in range(n)]
    return max(still), np.percentile(move, 95)


if __name__ == '__main__':
    still, move = check_estimate(H19, 1, 4)
    assert still <= 1.0 and move <= 0.5, (still, move)
    print(f'OK 정지 최대 {still:.2f} mm, 200 mm/s p95 {move:.2f} mm')
```

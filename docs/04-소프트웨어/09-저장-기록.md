# 저장과 기록

이 문서로 답하는 것: SQLite에 어떤 표를 두고 무엇을 저장하지 않나, JSONL 기록과 로그는 어디에 얼마나 두며 '기록 초기화'는 무엇을 지우나.

관련: [03 상태기계](03-상태기계.md) 3절 · [07 AI 실행](07-AI-실행.md) · [08 동반 앱](08-동반-앱.md) · [10 재생·시험](10-재생-시험.md)

## 1. SQLite

- 내장 `node:sqlite` `DatabaseSync(path, { timeout: 1000 })`, `PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;`. 쓰기 연결은 서비스 셸 하나, 동반 앱·로그는 읽기만.
- 한 입력 사건 = 트랜잭션 하나. 커밋 실패면 창·LED 명령 없음(REQ-036).
- 큐브에는 등록 번호·MAC만 둔다. 나머지는 모두 PC에 저장한다(REQ-015).
- 데이터 폴더 `%LOCALAPPDATA%\CubeSpace\`(`logs\`, `records\`, `runs\`, `claude-home\`, `codex-home\`). Electron `app.getPath`에는 LocalAppData 항목이 없어 `process.env.LOCALAPPDATA`로 찾는다.

| 표 | 칸 | 쓰는 쪽 |
|---|---|---|
| `window` | `id`, `win_key{hwnd, pid, proc_start}`, `app_id`, `launch{app_id, kind, arg}`(CUBE SPACE가 인자로 실행한 창만), `owner`, `protected`, `protect_cause`, `layout`(tiled·untiled·out), `off`, `home{x, y, w, h}`, `minimized_at` | 상태기계·엔진 |
| `layout` | `mode`('screen'), `tree_json`, `layout_ver`, `saved_at` | 엔진 |
| `minsize` | `app_id`, `dpi`, `w_px`, `h_px`, `source`(init·measured·learned) | 엔진 |
| `cube_seen` | `slot`, `mac`, `cube_boot_id`, `n_close`, `armed_protect`, `batt_last3`, `last_down_reason` | 상태기계 |
| `cube_ai` | `cube`, `ai_since` | 상태기계 |
| `cube_memory` | `slot`, `last_program{app_id, arg?}` | 상태기계 |
| `program_recent` | `app_id`, `arg?`, `used_at`(팝업 ③ 최근 프로그램) | 상태기계 |
| `meta` | `link_ver`, `last_pad_boot_id`, `mode` | 상태기계·게이트웨이 |
| `cube_reg` | `slot`, `mac`, `name`, `icon` | 등록 |
| `app_reg` | `app_id`, `exe_path`, `exe_names`, `color`, `icon` | 프로필 편집 |
| `profile` | 종류, `profile_id`, `ver`, 파일별 `sha256`, 본문 | AI 조정 |
| `run`·`step`·`judge`·`usage`·`ai_session` | `run.request_id` UNIQUE, 활성 행 부분 유일 색인, 단계 `pid`·실행 파일·생성 시각, 세션 ID | AI 조정 |
| `settings` | 키·값(REQ-065 항목, `PC를 켤 때 모드 자동 실행`) | 설정 |
| `shape_mode`(K8) | `name`, 큐브 번호·모양(쌍별 방향·붙음), 큐브별 프로그램 [미정 C2] | 상태기계 |
| `ai_preset`(K8) | 묶음 프로필 + 이름·아이콘·사용 강도, 큐브별 전환 가능 목록 | 동반 앱 |
| `interaction`(K7) | 가명 사용자 ID, 작업 유형, 프로필 ID·판, 배치 변경, 채택·거절, 재설정 횟수, 오류 유형, 단계 시간(ms). 수집 동의 켜진 동안만, PC 밖으로 안 보냄 | 동반 앱 |

- 저장하지 않는 것: 좌표·필터 값, 밀기 세션, 창 제목, 타이머 마감·무장·재실행 대기·팝업 상태·`presence`(재평가로 다시 만든다), AI 대화창 글.
- 표 이름·칸은 이 문서가 잠정으로 정한 것이다. 마이그레이션은 버전 번호 하나로 앞으로만 간다.
- `launch`(복원 인자)는 창이 닫히거나 연결이 풀리면 지운다. `lastProgram`·`program_recent`에는 앱 ID와 인자만 두고 창 제목·URL 쪽 정보는 두지 않는다. 인자에 든 폴더·파일 경로는 실행에 필요해 저장하지만 로그에는 쓰지 않는다.

## 2. 기록 파일

| 기록 | 위치·형식 | 보관 |
|---|---|---|
| 게이트웨이 원시 기록 | `records\` JSONL. 줄마다 `d`: `rx`·`tx`·`bad`·`port`·`meta`(첫 줄)·`meas`(`meas_id`·`pc_git`·`pc_dirty`·`pad_fw`·`cube_fw{슬롯}`·`cal_sha256`) | 7일과 전체 1 GB 중 먼저. `records\keep\`은 2026-12-20까지 |
| 상태기계 입력 사건 | `step`에 넣은 순서대로 JSONL. `pc_seq`·`pc_ns`·`src`(pad·sim·csv·csvfile·replay) | 같음 |
| AI 실행 폴더 | `runs\<run_id>\`(`spec.json`, 스냅샷, `steps\<step_id>\init.json`·`argv.json`(환경 변수는 이름만)·`last.json`) | 90일 |
| CLI 대화 | `claude-home\projects\`, `codex-home\sessions\` | 14일, 서비스 시작 때 지난 것 삭제 |
| 진단 로그 | `logs\`, 코드·수치만, 사용자 폴더 접두는 `%USERPROFILE%`로, 한 줄 2 KB | 14일, 10 MB × 5개 회전 |
| 측정 기록 | 측정 도구(CubeSpace 저장소 `measure/`)의 `logs/<test_id>/<run_id>/` | 게이트웨이 기록과 섞지 않음 |

- 기록·로그·오류에 넣지 않는 것: 창 본문·제목, 파일·폴더 경로, URL, 사용자 이름, 프롬프트 전문, 대화, 인증 정보(REQ-018). 어댑터 로그는 hwnd·pid·app_id·사각형·상태·판정값·시각·사유 코드만.
- 오류 기록에는 발생 시각·사유 코드·관련 큐브 번호를 남긴다(REQ-018).
- 발생량은 OBS만 약 1.25 GB/일, LED 포함 약 4.0 GB/일이라 7일·1 GB 상한이 먼저 닿는다.

## 3. 기록 초기화(`data.purge`, 특권)

| 지움 | 남김 |
|---|---|
| 진단 로그, `records\`(`keep\` 제외), `runs\`, CLI 대화 파일, `ai_session`, `cube_memory`·`program_recent`·`shape_mode` [미정 S7 ⑥] | 프로필, 등록 표, 설정, CLI 로그인, 서버 키(`server-key.bin`, [01 구성](01-구성.md) 2.1절), `records\keep\` |

- 내보내기는 없다. 장치 상태 화면에서 OS 확인 창을 거친다.

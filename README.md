# CUBE SPACE

물리 큐브를 센서 패드 위에 놓고 움직여 Windows 창 배치와 AI 작업(Claude Code·Codex)을 제어하는 시스템이다. 컴퓨터공학종합설계(2026-2) 캡스톤 프로젝트.

- 문서: [docs/README.md](docs/README.md)에서 시작한다. 처음이면 [아키텍처](docs/00-공통/01-아키텍처.md)부터 읽는다.
- 지금 이 저장소에는 문서(`docs/`)만 있다. 코드와 제작 파일은 이후 같은 저장소에 올린다.

## 무엇을 하나

| 모드 | 하는 일 |
|---|---|
| 화면 제어 | 큐브를 패드 위 창 자리에 놓으면 그 창과 묶인다. 빈 곳에 놓으면 고르는 팝업이 뜬다. 큐브를 밀면 창 경계가 움직이고, 들면 그 창이 최소화된다. 지원 앱은 VS Code·Edge·메모장 |
| AI | 큐브 조합으로 에이전트·프로젝트·프롬프트를 구성하고, 동반 앱에서 시작해 Claude Code → Codex 순서로 단계를 실행한다 |

모드 전환은 동반 앱 버튼으로 한다. 떠나는 모드의 배정은 그대로 남는다.

## 시스템 구성

```text
[큐브 × 최대 6]  ESP32-S3-Matrix + 셀 300 mAh
  접촉 스위치·버튼·배터리 → BLE 사건 / 바닥 IR LED는 자기 시간 칸에만 / 윗면 8×8 LED는 받은 아이콘만
        │ BLE
[패드 × 1]  ESP32-S3-Zero
  광센서 7 × 11 = 77 → 큐브별 광학 원시 창 / LED 24 × 16 = 384
        │ USB (SLIP + CRC-32)
[PC  Windows 11, Electron 동반 앱]
  게이트웨이 → 좌표 추정 → 상태기계 → 배치 엔진 → 창 어댑터(C#) → 실제 창
                                     → 표시(패드 LED·큐브 아이콘) / AI 조정(CLI 실행)
[도크 6칸]  충전 전용, 통신 없음
```

| 요소 | 하는 일 | 하지 않는 일 |
|---|---|---|
| 큐브 | 입력 확정, IR 발광, 아이콘 표시, 전원 관리 | 판정·좌표·상태 저장 |
| 패드 | 센서 읽기와 광학 판정, 큐브 사건 중계, 시각·순번 붙이기, LED 출력 | 좌표 계산, 놓임·묶기 판정 |
| PC | 모든 판단(좌표, 놓임·들림, 묶기, 배치, 창 명령, AI 조정, 표시, 저장) | |
| 도크 | 충전 | 통신 |

수량: 등록 큐브 6, 동시 연결 최대 6, 동시에 묶는 큐브 최대 4.

핵심 원칙: 판단은 PC에서만 한다. 판정 시각은 패드 시각이다. 판단 코드는 입출력 없는 순수 모듈이라 기록 재생·시뮬레이터로 하드웨어 없이 시험한다. 네트워크 포트를 열지 않는다. 기록에 창 제목·경로·프롬프트 같은 개인 내용을 남기지 않는다. 자세한 내용은 [아키텍처](docs/00-공통/01-아키텍처.md).

## 개발 환경

| 항목 | 값 |
|---|---|
| 대상 PC | Windows 11, 일반 사용자 권한, 주 모니터 1대(배율 고정) |
| PC 앱 | Node 24, Electron 44.4.5(정확 고정), npm workspaces, React, Vitest |
| 창 어댑터 | C#, .NET 10 LTS 자체 포함 단일 파일(게시는 Windows에서) |
| 펌웨어 | Arduino-ESP32 3.3.12 고정 + BLE 라이브러리 재빌드, arduino-cli |
| 펌웨어 호스트 시험 | `make -C firmware/host_test`. Windows는 MSYS2 UCRT64 셸 또는 WSL2 |
| Python 도구 | Windows는 `python3` 대신 `py` |

Windows에서 주의할 점(긴 경로·한글 사용자 이름, PowerShell 5.1의 `&&`, Python 기본 인코딩)은 [펌웨어 01](docs/02-펌웨어/01-구조-빌드.md)과 [proto-v1](docs/superpowers/plans/proto-v1.md)에 있다.

## 저장소 구조(코드를 올린 뒤)

| 폴더 | 내용 | 담당 |
|---|---|---|
| `docs/` | 구현 문서 | 팀장 양성우 |
| `firmware/` | 큐브·패드 펌웨어, 공용 규격 라이브러리, 호스트 시험 | 팀원 1 김도담 |
| `pc/` | 동반 앱(Electron + React)과 PC 서비스 모듈 | 아래 |
| `pc/gateway`, `pc/cube-events` | USB 게이트웨이, 상태기계 | 팀장 양성우 |
| `pc/estimate` | 좌표 추정 | 팀원 1 김도담 |
| `pc/engine`, `pc/win-adapter` | 배치 엔진, Windows 창 어댑터(C#) | 팀원 2 모가람 |
| `pc/src` | Electron main·preload·동반 앱 화면 | 팀장 양성우(IPC 검사), 팀원 2 모가람(화면·보안 골격) |
| `pc/cube-replay` | 기록 재생·시뮬레이터 | 미정 |
| `hardware/` | 큐브·패드 제작 파일(STL·도면·DXF·좌표·회로도)과 생성 스크립트 | 팀원 2 모가람 |
| `optics/`, `measure/` | 광학 상수 생성, 측정·교정 도구(Python) | 팀원 1 김도담, 팀장 양성우 |

코드 규칙: 판단 패키지(`engine`·`estimate`·`gateway`·`cube-events`·`cube-replay`)는 입출력·Electron·`Date.now()`·`Math.random()`을 쓰지 않는다. IPC 채널은 채널 목록·스키마·처리기를 같은 커밋에서 고친다. 의존성은 정확한 판으로 넣는다(`npm install -E`).
